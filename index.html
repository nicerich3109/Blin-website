01 · ОСНОВА

Discord остаётся платформой.
Настройка переезжает в веб.

◈

Вход через Discord

Пользователь авторизуется через Discord и видит только серверы, которыми имеет право управлять.

⌘

Без ID

Каналы, категории и роли выбираются из понятных списков. Никаких копирований длинных чисел.

✦

Быстрая настройка

Можно выбрать готовый сценарий и автоматически создать необходимую структуру для Blin Bot.

⚙

Настройки сервера

Каждый Discord-сервер получает собственную конфигурацию, а код бота остаётся общим.
